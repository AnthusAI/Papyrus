# Bundled CSL style

`apa.csl` is the "American Psychological Association 7th edition" style
(<http://www.zotero.org/styles/apa>) by Brenton M. Wiernik, from the
[CSL style repository](https://github.com/citation-style-language/styles),
licensed under
[Creative Commons Attribution-ShareAlike 3.0](http://creativecommons.org/licenses/by-sa/3.0/).

The file is byte-for-byte the `apa` template that `@citation-js/plugin-csl`
0.7.14 ships (`lib/styles.json`), which is the style the live anth.us site's
`gatsby-citation-manager` formats with. Do not edit it: matching that file is
what makes Markus citation text match the live site. The CC BY-SA licence
applies to this file only.
